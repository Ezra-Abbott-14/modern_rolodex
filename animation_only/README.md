# Rolodexi opening animation

This folder is a standalone copy of the opening animation used by the main app. It has no Rolodex data, API, or app controls.

Run it from the project root:

```sh
cd animation_only
python3 -m http.server 8001
```

Open <http://localhost:8001> in a browser. The animation shows the R first, resolves the full Rolodexi wordmark, then leaves the smaller logo visible as its end state.
